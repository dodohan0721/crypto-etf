# 화면 — ETF 자금흐름 대시보드

`index.html` 하나로 끝난다. 외부 라이브러리 없이 인라인 SVG 로 그린다.
읽는 데이터는 같은 폴더의 `etf.json` 하나뿐 (`build.py` 가 만든다).

## 열기

브라우저에서 파일을 직접 열면 보안 정책 때문에 `etf.json` 을 못 읽는다.
로컬 서버로 연다.

```bash
cd ~/Desktop/crypto-etf/web
python3 -m http.server 8000
# → http://localhost:8000
```

배포 시에는 이 폴더를 그대로 올리면 된다 (Cloudflare Pages 등).

## 담긴 것

- 시세 스트립 — 환율 · BTC/ETH 원화·달러 · 김치프리미엄
- ETF 순유입 — 최근값 + 기간 합계(7/30/90일)
- 순유입 추이 — 일별 자산별 누적 막대, 30일/1년/전체 전환, 호버 툴팁
- 총 AUM · 자산별 구성 · 시총 대비 흡수 비중
- 펀드 가격 추이 — 상위 5종목 전환, 100일 종가, 크로스헤어 툴팁
- 펀드 목록 — 자산 필터, 열 정렬, 선물·전략형 구분 표시
- **결합 뷰** — 가격 차트 아래 띠에 그날의 속보를 점으로 찍는다.
  주황 점은 중요 속보. 점을 누르면 그날 무슨 일이 있었는지 아래에 펼쳐진다.
  두 서비스를 붙이는 이유가 이 화면이다 — 가격이 움직인 날과 사건을 같은 축에서 본다.

라이트/다크 모두 대응하고, 색은 색맹 판별 검증(CVD ΔE)을 통과한 조합만 썼다.
