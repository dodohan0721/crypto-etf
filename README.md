# crypto-etf — 속보 × ETF 자금흐름 통합 플랫폼

한국투자증권 OpenAPI 하나로 미국 상장 크립토 ETF의 **가격 · 상장주식수**를 받아
**순유입과 AUM을 직접 계산**한다. 외부 크롤링은 쓰지 않는다.

## 구성

| 파일 | 역할 |
|---|---|
| `kis.py` | 한투 클라이언트 — 토큰 24h 캐시, 초당 16건 레이트리미터, 해외주식 조회 3종 |
| `funds.py` | 추적 ETF 19종목 정의 (거래소 코드는 실측 확정값) |
| `etf.py` | 스냅샷 수집 · 100일 가격 백필 · 순유입 산출 |
| `market.py` | 업비트·바이낸스 시세, BTC/ETH 유통량, ECOS 환율, 김치프리미엄 |
| `build.py` | 위를 합쳐 `data/etf.json` · `web/etf.json` 생성 |
| `sources.py` | 뉴스 소스·중요도 규칙·코인 태그 정의 |
| `news.py` | RSS·거래소 공지·네이버 뉴스 수집 → `web/news.json` |
| `web/index.html` | 화면 — 대시보드 + 속보 (외부 라이브러리 없음) |

## 실행

```bash
cd ~/Desktop/crypto-etf
python3 kis.py      # 연결 점검 — IBIT 현재가가 찍히면 정상
./run.sh            # ETF + 뉴스 전체 수집

cd web && python3 -m http.server 8000   # → http://localhost:8000
```

브라우저에서 `index.html` 을 직접 열면 보안 정책 때문에 JSON 을 못 읽는다.
반드시 로컬 서버로 열 것.

설정은 `~/Desktop/config.py` 에서 자동으로 읽는다 (환경변수가 있으면 그쪽 우선).
필요한 키: `KIS_APP_KEY`, `KIS_APP_SECRET`, `ECOS_API_KEY`.

## 순유입 산식

```
순유입(t) = ( 상장주식수(t) − 상장주식수(t−1) ) × 종가(t)
```

2026-08-25 검증: IBIT 1,351,560,000주 × $45.24 = **$61.145B**
vs 실제 순자산 **$61.190B** — 오차 **0.07%**.

## 알아둘 것

- **상장주식수는 과거 이력이 없다.** 한투는 현재 시점 값만 준다.
  그래서 순유입·AUM 시계열은 `.cache/shares/YYYYMMDD.json` 스냅샷을
  **쌓기 시작한 날부터** 만들어진다. 하루 한 번 `build.py` 를 돌리면 하루씩 길어진다.
- **가격 이력은 처음부터 100일**이 채워진다 (기간별시세 1회 호출 = 약 100일).
- **거래량(`tvol`)은 종목별 커버리지가 고르지 않다.** 0 으로 오는 종목이 있어
  `None` 으로 바꿔 화면에서 `—` 로 표시한다. 주지표는 순유입·AUM이다.
- `CETH` 는 거래소 코드를 못 찾아 제외돼 있다 (`funds.UNRESOLVED`).

## 캐시

```
.cache/kis_token.json      접근토큰 (24시간, 자동 갱신)
.cache/prices.json         티커별 날짜→종가 누적
.cache/shares/YYYYMMDD.json  일별 상장주식수 스냅샷 ← 순유입의 원천, 지우지 말 것
```


## 뉴스 저작권 원칙

`sources.py` 의 `SHOW_SUMMARY = False` 가 이 원칙을 코드로 강제한다.

- 저장·노출: **제목 + 언론사 + 발행시각 + 원문 링크**
- 저장 안 함: 기사 본문, 요약문

한국저작권보호원 기준상 **기사를 요약하여 게재하는 것도 이용허락 대상**이며,
영리 목적 이용은 손해배상 책임이 생길 수 있다.
언론사 또는 한국언론진흥재단과 계약을 맺은 뒤에만 `SHOW_SUMMARY = True` 로 바꾼다.

거래소 공지(업비트 등)는 언론 기사가 아니라 거래소가 직접 낸 고지라 성격이 다르고,
실제로 시세를 가장 크게 움직이므로 중요도를 최소 '상'으로 올려 잡는다.
